# 強い言葉の在庫

1行目に使う「インパクトのある言葉」の在庫です。使いすぎると読者が慣れて効かなくなるので、在庫を増やしながら回して使います（ルールB10：直近7投稿で同じ言葉を使わない）。

- 追加するのは `/collect-research` のとき、または人が見つけたとき（TikTokやYouTubeの冒頭、広告コピーなども対象）
- 「最終使用日」は、`/write-posts` が下書きで使ったときではなく、**実際に投稿したとき**に人が更新します
- 法令に触れやすい言葉（健康の効能、収益の保証）はこの在庫に入れません

| 言葉 | 型 | 出典・メモ | 最終使用日 | 状態 |
|---|---|---|---|---|
| 炎上覚悟で言います | 警告 | 動画の例。使われすぎているので注意 | - | 控える |
| 〇〇は危険です | 警告 | 動画の例 | - | 使える |
| 個人情報が漏れています | 警告 | 動画の例 | - | 使える |
| 知らないと損します | 損失回避 | - | - | 使える |
| 年収1000万超の〇〇さんが | 権威＋数字 | 動画の例。本人の話であることが条件 | - | 使える |
| 〇〇しないともらえないお金 | 損失回避＋お金 | 動画の例（妊婦向け） | - | 使える |
| 〇年やって分かった | 経験＋数字 | - | - | 使える |
| まだ〇〇してるんですか | 意外性 | 動画のAI投稿例 | - | 使える |

状態：`使える` / `控える`（使いすぎ・効果が落ちた） / `使わない`（炎上・法令リスク）
