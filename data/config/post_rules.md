# Threads 投稿ルール

投稿案の作成と審査は、すべてこのファイルに従います。ルールの変更は週次の振り返り（`/weekly-review`）で本人が合意したときだけ行い、変更履歴を末尾に残します。

- 【動画】＝元動画のノウハウ（文字起こし（別ブランチ `claude/transcription-review-tdddqg` の `docs/source/`。第三者の著作物のためこのブランチには置かない））
- 【追加】＝[批判的検証](../../docs/strategy/video-critical-review.md)を受けて追加・修正したもの

## 0. 前提

- 1投稿の上限は500字です（本文とコメント欄それぞれ）。
- 投稿は「本文」と、投稿者自身の最初の返信である「コメント欄」の2つで1セットです。
- 投稿する前に、必ず人が目を通して採否を決めます。【動画】ただし 2026-10-06 から本人の判断で全自動運用（`settings.json` の `require_human_approval: false`）。人の確認の代わりに post-reviewer の審査（80点以上）と validate を必ず通す。
- アカウントのジャンル・読者・収益導線は [account_profile.md](account_profile.md) に従います。【追加】

## 1. 目的と指標

- 本文の目的は、読者にコメント欄を開かせることです。【動画】
- アカウントの目的は、プロフィールを見てもらい、フォローと導線クリックにつなげることです。【動画】
- 「タップ数」はインサイトで見られません。投稿ごとに取れるのは閲覧・いいね・返信・リポスト・引用・シェアです。フォローへのつながりは、1日1投稿にして「翌日までのフォロワー増」で近似します。【追加】

## 2. 本文のルール

**最優先：2秒ルール（2026-10-07 本人指示）** 読者はテーマに詳しくないライトユーザー。タイムラインで**2秒見て「読みたい」と思えるか**を何より優先する。専門性は返信と図解カードの裏側で支え、本文には出さない。

| # | ルール | 出典 |
|---|---|---|
| B0 | **1行目は20字以内**（最大25字）。中学生でも分かる日常の言葉だけで書く。**専門用語・英字の略語・規格名（Ra・lm・K・JIS・演色・全光束・配光 など）は本文に入れない**（返信で、言い換えつきで1回だけ使う）。数字を入れるなら1つまで、日常の単位で（「3か所」「1つ」） | 本人指示 |
| B1 | **1行目は一瞬で意味が分かる文にする。** 次の3要素のうち**2つ以上**を入れる：①インパクトのある言葉 ②意外性（読者の常識を反転させる） ③具体的な固有名詞・数字（商品名・金額・年数・人数など） | 動画（「2つ以上」は追加） |
| B2 | 抽象的な言葉（「話題の〜」「すごい〜」「今年覚える名前」など）を1行目に使わない。固有名詞で言い切る | 動画 |
| B3 | 本文は**3〜4行・80字以内**に収める（旧：3〜8行。2秒ルールにより短縮） | 動画（本人指示で短縮） |
| B4 | 冗長な言葉を削る：「そもそも」「やっぱり」「〜くらい」「〜的な」「〜という」「実は」「ガチで言います」など、なくても意味が通る言葉。同じ内容を30字でも10字でも言えるなら10字にする | 動画 |
| B5 | 本文では曖昧な表現を使わない：「〜と思う」「〜かもしれない」「〜らしい」「多分」 | 動画 |
| B6 | **言い切るのは、根拠を示せる範囲だけにする。** 言い切れないときは、主張を狭めて言い切る（例：「アマニは体に悪い」→×、「アマニの摂り方を間違えている人が多い」→○）。それでも無理なら書かない | 追加 |
| B7 | 目立たせたい言葉は「」で囲み、パッと見て言葉のまとまりが分かるようにする（8行中2〜4か所が目安） | 動画（目安は追加） |
| B8 | 答えを書かずに、読者がいちばん知りたいところの直前で終える。最後は「→」「…」「〜がこちら」などでよい。「続きはコメント欄」と書かなくてもよい | 動画 |
| B9 | 「いいねして」「フォローして」「コメントして」など、反応を直接求めない | 追加（釣り投稿として表示を下げられるリスク） |
| B10 | 強い言葉は [power_words.md](power_words.md) から選び、**直近7投稿で同じ言葉を使わない** | 動画（頻度の上限は追加） |

## 3. コメント欄（自己返信）のルール

| # | ルール | 出典 |
|---|---|---|
| C1 | **本文で予告した答えを、1行目で必ず回収する。** 回収しないのは釣りとして禁止 | 追加 |
| C2 | 1行目で答えを**20字前後の言葉**で言い切る。続く具体策（手順・一覧）は短い箇条書きで、全体**150〜300字**。専門用語は「Ra（色の見え方の数字）」のように言い換えを添えて1回だけ | 動画（本人指示で短縮） |
| C3 | 曖昧な表現を使ってよい（ただし事実の誤りは不可） | 動画 |
| C4 | 事実・数字・制度には出典（公式サイト名やURL）を添える | 追加 |
| C5 | プロフィール・固定投稿・リンクへの誘導は最後に1行だけにする。本文にはリンクを貼らない。商品・サービスを紹介する投稿は週2本まで | 追加 |

## 4. 法令・安全のルール（コンプラ審査で1つでも違反したら却下）【追加】

| # | ルール |
|---|---|
| L1 | 報酬が発生するリンクや案件を含む場合は、本文の冒頭に「PR」などを入れる（景品表示法のステマ規制、2023年10月施行）。案件ごとのSNS掲載の可否と、使ってはいけない表現（ASPの規約）にも従う |
| L2 | 健康・美容：病気の治療・予防・効果を断定しない（薬機法・健康増進法） |
| L3 | お金・副業：「誰でも稼げる」「必ず儲かる」など、収益を保証する表現をしない。実績の数字は根拠がある自分の数字だけ使う |
| L4 | 実在の個人・企業を誹謗しない。他人の投稿をそのまま写さない（参考にしてよいのは構造だけ） |
| L5 | 事実でないことを、意外性のために事実として書かない |
| L6 | 勤務先の機密・社内情報を書かない。所属が分かるアカウントなら、就業規則・SNSポリシーに従う |
| L7 | 著作権・画像：他人の写真・投稿を転載しない（Pinterest の画像を含む）。使える画像は自分で撮ったものだけ。商品画像は楽天アフィリエイトの規約で許された方法だけで使う |
| L8 | 住まいの特定：地名・建物名・間取り・階数・窓の外の景色・工期の日付・施工会社名を出さない（account_profile.md 7章） |

## 5. 出力形式

投稿は `data/queue/*.json` の1ファイルで表します（形式は `data/queue/EXAMPLE.json.sample`）。

| ルール上の呼び方 | キューのフィールド |
|---|---|
| 本文 | `text` |
| コメント欄（自己返信） | `replies[0]`（公開時に本文への返信として自動でつながる） |
| 柱 | `tags`（柱名を1つ。例 `["①評価"]`） |
| 1行目の要素・使った強い言葉・PR表記・出典・使った一次情報 | `review.notes` に1行ずつ |

## 6. 修正指示の書き方（人→AI）【動画】

問題のある箇所・理由・直し方を1文ずつ書きます。

> 案3の1行目「今年覚える名前は」は抽象的でピンとこないので「今年覚えるべきAIは」に変えて。本文1行目の「ガチで言います」は意味がないので削除して。
