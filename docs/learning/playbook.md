# 学習メモ（プレイブック）

投稿のインサイトから学んだことを積み上げる場所。**週2回の投稿づくりの最初に必ず読み、最後に更新する。**
数値の元データは `data/learning.json`（毎朝 06:13 に自動更新）と `data/reports/`。

## 学習のルール
1. 判断は `data/learning.json` の `decision` に従う（3本未満は「検証中」、指数1.2以上で「増やす」、5本以上かつ0.75未満で「減らす」）。思いつきで配分を変えない。
2. 配分は **7割を学びの活用、3割を検証**（`exploration_share`）。「減らす」の型・柱もゼロにはせず、検証枠で切り口を変えて試す。
3. 教訓は「仮説 → 根拠（指数・本数）→ 次にやること」の形で書く。本数が少ないものは「仮説」と明記する。
4. 自動で変えてよいのは、型・柱・時間帯・画像の有無・1行目の作り方の**配分**だけ。次は変えない（変えたいときはユーザーに提案する）：
   - 投稿ルール（post_rules.md）、書かないこと（account_profile.md 7章）、NGワード、身バレ判定語
   - 投稿本数・投稿枠・承認の設定
5. フォロワーの増減（`followers.change_7d`）も見る。閲覧が伸びてフォロワーが増えないときは、釣りになっていないか（コメント欄で回収できているか）を疑う。
