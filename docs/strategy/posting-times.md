# 投稿時間（ゴールデンタイム）の根拠（2026-10-07）

## 結論
| | 朝 | 昼 | 夜 |
|---|---|---|---|
| 平日 | **07:15** | **12:05** | **21:00** |
| 土日 | **09:45** | **13:00** | **21:00** |

- 狙いは「見る人が一番多い時間帯の**入り口**に出す」こと。Threads は公開後1時間の反応で広がり方が変わりやすい（一般論。Meta 公式の数値は未確認）ため、ピークが始まる直前〜直後に置く。
- この時間は**仮説**。毎朝の分析が朝・昼・夜の差を学習し、根拠がそろったら（各時間帯5本以上）見直す。

## 根拠
### 1. 日本で人がネットを使う時間（需要側）— 総務省（tier S）
令和3年版 情報通信白書「主なメディアの時間帯別行為者率」（2020年調査）のネット利用：
| 時間帯 | 平日 | 休日 |
|---|---|---|
| 7時台 | 21.6% | 11.2% |
| 8時台 | 22.7% | 20.3% |
| 10時台 | 23.5% | **28.6%** |
| 12時台 | **35.2%** | 23.6% |
| 13時台 | 23.8% | 26.5% |
| 20時台 | 33.0% | 34.8% |
| 21時台 | **39.2%** | **39.2%** |
| 22時台 | 37.7% | 34.7% |

- 平日は「朝・昼休み・夜」の3つの山。最大は21時台、次いで22時台・12時台。
- 休日は朝の山がなく（7時台11.2%）、10時台に1つ目の山、21時台が最大。→ 土日の朝枠を 07:15 → 09:45 に移した理由。
- 出典：https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r03/html/nd242520.html （CSV：r03/csv/n4205020.csv）

### 2. Threads で反応が多い時間（投稿1本あたり）— Buffer（tier B）
Buffer が自社経由の約250万投稿を分析（指標は反応数の中央値。時刻は各アカウントの現地時間）：
- 強いのは**平日の朝 6〜11時**。上位は木9時・水12時・水9時・木10時・木11時。
- **夜 18〜23時は全曜日で弱い**。土曜が最も弱い。
- 出典：https://buffer.com/resources/the-best-time-to-post-on-threads/
- 注意：利用者は主に英語圏。「1本あたりの反応」なので、人が多い夜ほど**投稿も多く競争が激しい**ことを反映している可能性がある。日本の Threads に限った時間帯データは、公的・大規模なものが見つからなかった。

### 3. 2つの食い違いをどう扱ったか
| 時間帯 | 総務省（人の多さ） | Buffer（1本あたりの反応） | 判断 |
|---|---|---|---|
| 平日朝 | 中 | **強い** | 残す。通勤の山の入り口 07:15 |
| 昼 | **強い**（平日） | 強い | 昼休みの最初 12:05（12時台の中で1時間を使い切る） |
| 夜 | **最強** | 弱い（競争） | 残す。読者（社会人）がくつろいで見る時間。ただし競争が激しいので、1行目の強さが特に問われる |
| 土日朝 | 弱い（7時台） | — | 09:45 に後ろ倒し |

## 反論と答え
- **「夜は Buffer で最弱。夜をやめて朝を2本にすべきでは」** → Buffer は英語圏・1本あたりの指標。日本の総務省データでは夜が最も人が多い。どちらが当たるかはこのアカウントの数字で決める（学習ループが朝・昼・夜を比較）。夜が5本以上で「減らす」判定になったら、夜枠を朝・昼に振り替える提案をする。
- **「時間より中身では」** → その通り。Buffer も「時間より中身が大事」と書いている。時間は1行目・図解ほどの差は生まない前提で、外さないことを目的にする。
- **「15分ずらしても誤差では」** → GitHub Actions の起動は数分〜十数分遅れる。枠を山の入り口に置いておけば、遅れてもピーク内に収まる。

## 失敗パターン
1. 枠の時刻だけ変えて、公開処理（`.github/workflows/publish.yml` の cron）を合わせ忘れる → 最大1時間遅れる。今回は cron も合わせて変更済み。
2. 少ない本数で「朝が強い」と決めつける → 判定は学習ルール（3本未満は検証中、5本以上で減らす）に従う。
3. 祝日を平日扱いする → 今は土日だけ休日枠。祝日（例：11/3・11/23）は平日枠のまま。必要なら手動で調整する。
